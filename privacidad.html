Política de privacidad de Chatask

Última actualización: 7 de noviembre de 2026.

Quién la ofrece

Chatask es una aplicación personal de escritorio desarrollada y usada por Oscar Herrera. Contacto: oman.hp@gmail.com.

Qué datos maneja

  • Datos de trabajo: tareas, contactos, pedidos y fichas de archivos que el usuario crea. Se guardan en una base de datos local en su equipo.
  • Archivos que el usuario descarga desde WhatsApp Web dentro de la aplicación. Se guardan en una carpeta local de su equipo.
  • WhatsApp Web funciona dentro de la aplicación como un navegador. Chatask no envía mensajes, no importa conversaciones y solo usa el texto que el usuario elige para crear una tarea.

Uso de los datos de Google

Si el usuario conecta su cuenta de Google, Chatask solicita únicamente el permiso drive.file. Con él puede ver y modificar solo los archivos de Google Drive que la propia aplicación crea. No accede a otros archivos, correos, contactos ni calendario.

  • Uso: guardar y recuperar respaldos de los datos de trabajo del usuario en una carpeta de su propio Google Drive.
  • El acceso a Google se guarda cifrado en el equipo del usuario.
  • Los datos de Google no se venden, no se comparten con terceros, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial.
  • Los datos no se envían a ningún servidor del desarrollador: solo viajan entre el equipo del usuario y su propio Google Drive.

El uso que hace Chatask de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

El usuario puede desconectar Google en Chatask (Ajustes › Google Drive) o retirar el permiso en myaccount.google.com/permissions. Los respaldos ya guardados en su Drive quedan bajo su control y puede eliminarlos cuando quiera.

Cambios

Si esta política cambia, se actualizará esta página con una nueva fecha.
